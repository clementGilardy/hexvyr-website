Two moments in a match

HEXVYR runs beside the League client on Windows. It focuses on champion select and the live game—where contextual information helps most.

Champion select

See the lobby before the game starts

The champion-select overlay surfaces relevant information about allies, opponents, and champion matchups while the draft is underway.

In game

Keep context during the match

The in-game overlay presents contextual champion, item, and gameplay information where the current build supports it—without taking over your screen.

Built to stay local

HEXVYR is a personal desktop tool. It is not a web app and does not require a HEXVYR login.

  • Your machine. Settings, your optional Riot API key, and game-data caches live under Windows user data on the PC that runs HEXVYR.
  • Riot data where it belongs. When you supply a Riot API key, HEXVYR calls Riot Games APIs and Data Dragon resources directly from your computer for player, match, and static game data.
  • No HEXVYR backend. There is no HEXVYR account system and no HEXVYR remote server collecting your play data.

HEXVYR is an independent Windows companion for League of Legends. Product status, privacy details, and data handling are documented on this site.
