Privacy

This page describes how the HEXVYR desktop application handles data, based on the current product behavior. It is not legal advice.

Summary

HEXVYR is a local Windows desktop application. It does not create HEXVYR user accounts and does not operate a HEXVYR cloud service that receives your gameplay data. Data used by the app is processed on your computer and, when you choose to enable them, requested from Riot Games services and related public game-data CDNs.

This website

The public product pages on GitHub Pages are static files. They do not use analytics scripts, advertising trackers, or cookies. Visiting these pages does not send product telemetry to HEXVYR.

What HEXVYR accesses

  • Local League Client (when the client is running). HEXVYR reads champion-select and related session information from the League client on your machine so overlays can reflect the current lobby.
  • Local Live Client Data (during a match). During loading and live games, HEXVYR may read the official local Live Client Data API on your machine for in-match context.
  • Riot Games API (optional). If you paste a personal Riot API key and a Riot ID into settings, HEXVYR calls Riot Games APIs from your computer for account, match, ranked, and related player information you request in the app.
  • Static game data. HEXVYR downloads champion, item, and related catalog data and icon URLs from Riot Data Dragon (and may reference Community Dragon asset URLs for some imagery). Catalog files can be cached on disk for reuse.

What HEXVYR stores on your PC

On Windows, application data lives under the HEXVYR user-data directory (typically %APPDATA%\HEXVYR). Depending on use, this may include:

  • Local settings such as Riot ID fields, platform preference, overlay-related preferences, and—if you save one—your Riot API key in app-settings.json.
  • Saved overlay window positions in overlay-bounds.json.
  • A local Data Dragon catalog cache.
  • Short-lived in-memory caches for match history and related responses while the application is running.

The Riot API key is stored locally for the app to use. It is not displayed back in the settings UI after being saved, and it is not sent to a HEXVYR server.

What HEXVYR does not do

  • It does not require a HEXVYR account or password.
  • It does not run a HEXVYR remote backend that stores your matches or API key.
  • It does not sell personal data.
  • This website does not claim that “no data is collected” in every sense: the desktop app necessarily processes game and player data locally, and optional Riot API calls send requests from your machine to Riot.

Third parties

When Riot API, Data Dragon, Community Dragon, or the League client local endpoints are used, those services process requests according to their own terms and policies. HEXVYR does not control Riot Games’ systems.

Changes
